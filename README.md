# Sobre o Desenvolvimento

Este é meu primeiro projeto web e espero aprender muito ao longo do seu desenvolvimento. O objetivo principal é criar um site de tutoriais voltado para futuros cientistas da computação - um espaço onde eu possa compartilhar o conhecimento que adquiri durante a graduação.
O conteúdo vai cobrir desde os fundamentos teóricos, como sistemas de numeração, lógica para computação, cálculo e teoria dos números, até tópicos mais práticos, como estruturas de dados, algoritmos, linguagens de programação e frameworks.

Quero aprender a desenvolver um site do zero, entendendo não só HTML, CSS e JavaScript, mas também como organizar um projeto de forma escalável - estrutura de pastas, separação de responsabilidades e boas práticas de arquitetura front-end. Além disso, quero dominar o fluxo de trabalho com Git e GitHub, incluindo padrões de commit, uso de branches e outras práticas usadas no desenvolvimento profissional.

# Referências

### Estrutura básica - por onde começar

[MDN Web Docs](https://developer.mozilla.org/en-US/docs/Learn_web_development/Getting_started/Environment_setup/Dealing_with_files) - referência oficial, explica a estrutura mínima de qualquer projeto web.

### Projetos médios e grandes (vanilla HTML/CSS/JS)

[Appcropolis](https://appcropolis.com/blog/organize-html-css-javascript-files) - explica como separar arquivos globais de arquivos específicos por página, com exemplos práticos.

### CSS escalável - como organizar seus estilos

[DEV.to](https://dev.to/jenc/how-to-plan-scalable-css-for-large-projects-47i4) - Scalable CSS for Large Projects - apresenta as metodologias SMACSS, BEM e OOCSS, que são padrões amplamente usados para organizar CSS em projetos grande.
