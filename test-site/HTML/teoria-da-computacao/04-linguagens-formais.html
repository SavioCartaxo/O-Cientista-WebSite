Linguagens Formais e Gramáticas

Neste artigo, exploramos os fundamentos das linguagens formais na Teoria da Computação. Começamos pelos conceitos básicos, como alfabetos e cadeias, passamos pelos modelos de máquinas abstratas responsáveis por reconhecer linguagens, e chegamos às gramáticas, que descrevem como essas linguagens são geradas.

Ao final, você terá uma visão clara de como esses conceitos se conectam e por que são essenciais para áreas como compiladores, interpretadores e o estudo dos limites da computação.

O que é uma Linguagem Formal?

No dia a dia, usamos a palavra "linguagem" para nos referir a formas de comunicação - português, inglês, libras. Na Teoria da Computação, o conceito é semelhante, mas mais preciso: uma linguagem formal é definida como um conjunto de elementos (símbolos, caracteres, palavras, entre outros) e um conjunto de métodos (regras) para combinar esses elementos, usado e entendido por uma determinada comunidade. Em termos práticos, uma linguagem formal é composta por dois elementos fundamentais:

  • sintaxe: as regras que definem quais combinações de símbolos são válidas.
  • semântica: o significado atribuído a essas combinações.

Você já viu isso em linguagens de programação: existem regras sintaxicas que definem o que é um código válido, enquanto isso, cada script que você faz realiza alguns passos para cumprir um propósito, e isso chamamos de semântica.

Linguagens formais são, portanto, mecanismos matemáticos para representar e especificar linguagens de forma precisa e não ambígua - algo essencial para que um computador possa interpretá-las corretamente.

Alfabeto e Cadeias

Toda linguagem formal é construída a partir de elementos básicos chamados símbolos. Um símbolo é a unidade indivisível de uma linguagem - pode ser uma única letra ou até mesmo uma palavra inteira, como if ou else, desde que seja tratada como um único elemento.

Um alfabeto, geralmente representado pela letra grega Σ (sigma), é um conjunto finito e não vazio de símbolos.

Exemplos de alfabetos: Σ = { a, b, 0, 1 } ou Σ = { if, then, else }.

A partir de um alfabeto, podemos formar cadeias (ou strings), que são sequências finitas de símbolos.

Se Σ = { a, b, 0, 1 }, então exemplos de cadeias são: ab, aba, a0b1 e 01. A cadeia sem símbolos é chamada de cadeia vazia e é representada por ε.

Prefixos e Sufixos

Uma cadeia pode ser analisada a partir de suas partes. Um prefixo é uma sequência inicial da cadeia, enquanto um sufixo é uma sequência final.

Para a cadeia a0b1, temos:

  • prefixos: ε, a, a0, a0b, a0b1
  • Sufixos: ε, 1, b1, 0b1, a0b1

Operações com Cadeias

Podemos realizar diversas operações com cadeias.

O reverso de uma cadeia é obtido invertendo a ordem dos símbolos. Por exemplo, se α = a01b, então seu reverso é αR = b10a.

A concatenação consiste em juntar duas cadeias. Se α = ab e β = bb, então:

  • α · β = abbb
  • β · α = bbab
  • α · ε = ab
  • α · α · α = ababab

Também podemos repetir uma cadeia várias vezes. A notação xk representa a concatenação de x com ele mesmo k vezes.

Comprimento e Conjuntos de Cadeias

O comprimento de uma cadeia α, representado por |α|, é a quantidade de símbolos que ela possui.

O conjunto de todas as cadeias de tamanho k sobre um alfabeto Σ é representado por Σk.

Se Σ = { a, b }, então:

  • Σ0 = { ε }
  • Σ1 = { a, b }
  • Σ2 = { aa, ab, ba, bb }

O conjunto Σ* representa todas as cadeias possíveis (incluindo a vazia), enquanto Σ+ representa todas as cadeias não vazias.

Ordem das Cadeias - Ordem Lexicográfica

As cadeias podem ser organizadas em uma ordem lexicográfica, semelhante à ordem das palavras de um dicionário.

Existe também a ordem shortlex, onde cadeias menores vêm antes das maiores, e em caso de empate, utiliza-se a ordem lexicográfica.

Exemplo: ε, 0, 1, 00, 01, 10, 11, 000, ...

Gramática

Uma gramática é um conjunto de regras que define as cadeias de uma linguagem. A gramática especifica como as cadeias podem ser formadas a partir de um alfabeto, determinando quais cadeias são válidas na linguagem.

Uma gramática é um conjunto finito de regras formais que descreve a sintaxe de uma linguagem, ou seja, define como as sentenças dessa linguagem podem ser formadas. De forma informal, podemos pensar em uma gramática como um sistema gerador de linguagens - ela descreve, de maneira finita e precisa, um conjunto potencialmente infinito de sentenças válidas.

Formalmente, uma gramática pode ser definida como uma tupla G = (V, Σ, R, S), onde:

Elemento Símbolo Definição Exemplo Explicação do Exemplo
Regras de Produção R Conjunto de regras que definem como os símbolos podem ser substituídos durante a geração das cadeias. S → aS
S → b		 A regra permite substituir S por "aS" (continuando o processo) ou por "b" (encerrando a cadeia).
Símbolo Inicial S Elemento a partir do qual a geração das cadeias começa. S → aS → aaS → aaab Começamos com S e aplicamos regras até obter apenas símbolos terminais, formando a cadeia final "aaab".
Não-terminais V Conjunto de símbolos usados como partes intermediárias na construção das cadeias. Não aparecem no resultado final. V = {S, A} Aqui, S representa a estrutura principal da linguagem, enquanto A representa uma parte auxiliar. Ambos serão substituídos até desaparecerem.
Terminais Σ Conjunto de símbolos definitivos da linguagem. Formam as cadeias finais e não podem ser substituídos. Σ = {a, b} As cadeias resultantes finais serão formadas apenas por 'a' e 'b', como "ab", "aab" ou "b".

Para entender como esses elementos funcionam juntos, vamos considerar uma gramática simples que gera cadeias formadas por várias letras "a" seguidas de uma única letra "b", como: b, ab, aab, aaab, entre outras.

Essa gramática pode ser descrita pelas seguintes regras:

S → aS

S → b

O processo começa a partir do símbolo inicial S. A cada passo, aplicamos uma das regras de produção:

S → aS → aaS → aaaS → aaab

Em cada etapa, substituímos o símbolo não-terminal S por outra cadeia, de acordo com as regras. Enquanto ainda existir um símbolo não-terminal, o processo continua. Quando restarem apenas símbolos terminais (neste caso, "a" e "b"), obtemos uma cadeia válida da linguagem.

Nesse exemplo, podemos identificar claramente cada elemento da gramática:

  • S é o símbolo inicial, de onde a geração começa.
  • V contém os símbolos não-terminais (como S), usados durante a construção.
  • Σ contém os símbolos terminais (como a e b), que formam as cadeias finais.
  • R é o conjunto de regras que define como as substituições acontecem.

Um exemplo prático: em Python, a gramática da linguagem define que um bloco if deve ser seguido de uma condição e terminar com ":", e que o corpo do bloco deve ser indentado. Se você escrever if x > 5 sem os dois pontos, o interpretador identifica imediatamente que a sentença não pertence à linguagem - é um erro de sintaxe. É exatamente essa gramática que permite ao Python distinguir código válido de código inválido antes mesmo de executá-lo.

Derivação

As regras de produção de uma gramática são utilizadas para gerar cadeias por meio de um processo chamado derivação. Nesse processo, substituímos partes de uma cadeia por outras, de acordo com as regras definidas na gramática.

De forma geral, se uma regra de produção permite substituir uma cadeia por outra (por exemplo, v → w), então qualquer cadeia que contenha v pode ser transformada substituindo esse trecho por w. Assim, uma cadeia como "avb" pode ser transformada em "awb" ao aplicar essa regra.

Essa transformação pode ser representada de forma simbólica.

avb ⇒ awb

Dizemos que uma cadeia U deriva uma cadeia V se for possível transformar U em V aplicando uma ou mais regras de produção. Isso é representado por U ⇒ V, e significa que:

  • U e V são iguais.
  • ou existe uma sequência de transformações que começa em U e, após a aplicação de regra(s), resulta em V.

A partir desse conceito, podemos definir a linguagem gerada por uma gramática como o conjunto de todas as cadeias formadas apenas por símbolos terminais que podem ser obtidas a partir do símbolo inicial S. Em outras palavras, são todas as cadeias w tais que S ⇒* w.

Resumo

  • Linguagem Formal: conjunto de símbolos(alfabeto) + conjunto de regras(gramatica) para combinar os símbolos.
  • Alfabeto (Σ): os simbolos que compõem uma linguagem para formar cadeias.
  • Cadeia (string): sequência finita de símbolos de um alfabeto.
  • Cadeia vazia (ε): cadeia sem símbolos.
  • Prefixo / Sufixo: partes inicial e final de uma cadeia.
  • Concatenação (α · β): denota a junção de duas cadeias.
  • Operações com cadeias
    1. Reverso (αR): denota a cadeia com a ordem dos símbolos invertida.
    2. Comprimento (|α|): denota o número de símbolos de uma cadeia.
    3. Σk: denota o conjunto de todas as cadeias de tamanho k.
    4. Σ*: denota o conjunto de todas as cadeias possíveis (incluindo ε).
    5. Σ+: denota o conjunto de todas as cadeias não vazias.
  • Gramática: Conjunto de regras que formam as cadeias.
  • sintaxe: regras que definem quais combinações de símbolos são válidas.
  • semântica: significado atribuído a essas combinações.
