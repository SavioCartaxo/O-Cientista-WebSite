Tipos de Problemas na Teoria da Computação

Na Teoria da Computação, os problemas são classificados de acordo com o tipo de resposta que se deseja obter. Essa classificação ajuda a entender como diferentes problemas podem ser resolvidos e quais técnicas são mais adequadas para cada caso.

1 - Problemas de Decisão

Problemas de decisão são aqueles cuja resposta é simplesmente sim ou não. Um exemplo clássico é: "um número inteiro é par?". Esse é o tipo de problema mais estudado, pois muitos outros problemas podem ser reduzidos a ele.

Exemplos:

  • Um número inteiro é primo?
  • Um grafo possui um caminho entre dois pontos?
  • Uma palavra pertence a uma linguagem?

2 - Problemas de Otimização

Problemas de otimização buscam encontrar a melhor solução possível entre várias alternativas, de acordo com algum critério. Por exemplo: "qual é a menor quantidade de moedas necessária para um troco?".

Exemplos:

  • Minimizar a quantidade de moedas em um troco.
  • Distribuir tarefas minimizando o tempo total.

3 - Problemas de Enumeração

Problemas de enumeração exigem listar todas as soluções possíveis. Por exemplo: "quais são todos os caminhos possíveis entre dois pontos?". Esses problemas costumam crescer rapidamente com o tamanho da entrada.

Exemplos:

  • Listar todas as permutações de uma lista.
  • Listar todos os caminhos em um grafo.
  • Listar todos os subconjuntos de um conjunto.

4 - Problemas de Busca ou Construção

Problemas de busca ou construção exigem que o algoritmo encontre ou construa uma solução que satisfaça determinadas condições. Diferentemente dos problemas de otimização, aqui não é necessário encontrar a melhor solução - qualquer solução válida é suficiente. Diferentemente dos problemas de decisão, não basta responder sim ou não - é preciso apresentar a solução concreta.

Exemplos:

  • Encontrar qualquer caminho entre dois pontos em um grafo.
  • Construir uma sequência de movimentos que resolva um cubo mágico.
  • Encontrar um número que satisfaça uma equação.
