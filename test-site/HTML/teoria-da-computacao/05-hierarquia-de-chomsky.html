Hierarquia de Chomsky

Neste artigo, exploraremos a Hierarquia de Chomsky - uma classificação das linguagens formais de acordo com seu poder expressivo e computacional. Para facilitar a compreensão, utilizaremos um mesmo alfabeto base ao longo de todos os exemplos, observando como cada nível da hierarquia consegue impor regras progressivamente mais complexas.

A Hierarquia de Chomsky

Em 1959, o linguista e matemático Noam Chomsky propôs uma classificação das linguagens formais de acordo com seu poder expressivo e computacional - conhecida hoje como a Hierarquia de Chomsky. Essa hierarquia divide as linguagens em quatro tipos, do menos ao mais poderoso, cada um associado a um tipo de gramática e a um modelo de máquina capaz de reconhecê-la.

Para mencionado anteriormente, vamos utilizar uma mesma linguagem base ao longo de todos os exemplos: um alfabeto formado pelos símbolos {a, b, c, d, e}. A ideia é observar como cada tipo da hierarquia consegue impor regras cada vez mais complexas sobre essas letras.

Tipo 3 - Linguagens Regulares

As linguagens regulares são o tipo mais simples da hierarquia. Elas conseguem reconhecer padrões básicos, mas não são capazes de "lembrar" quantidades arbitrárias de símbolos. Ou seja, conseguem identificar sequências e repetições simples, mas não conseguem garantir relações entre partes distantes da palavra.

Por exemplo, podemos definir uma linguagem onde aparecem primeiro várias letras a, seguidas de várias letras b, sem nenhuma relação entre as quantidades: L = { aⁿ bᵐ | n ≥ 0, m ≥ 0 }.

Essa linguagem aceita palavras como ε, a, b, aaab, bbbb e aaaaabbbbb. Note que não importa quantos a ou b existem - não há nenhuma dependência entre eles.

Tipo 2 - Linguagens Livres de Contexto

As linguagens livres de contexto possuem maior poder expressivo. Elas conseguem impor dependências entre partes da palavra, como exigir que certas quantidades sejam iguais. Isso é possível porque utilizam pilhas como estruturas de memória auxiliares.

Um exemplo clássico é a linguagem L = { aⁿ bⁿ | n ≥ 0 }, onde o número de letras a deve ser exatamente igual ao número de letras b.

São palavras válidas: ε, ab, aabb, aaabbb. Já palavras como aab, abb ou aaabbbb não pertencem à linguagem, pois quebram essa igualdade.

Aqui já é necessário "lembrar" quantos a apareceram para depois comparar com os b.

Tipo 1 - Linguagens Sensíveis ao Contexto

As linguagens sensíveis ao contexto conseguem impor regras ainda mais complexas, envolvendo múltiplos símbolos ao mesmo tempo. Agora não basta comparar duas quantidades - podemos exigir relações entre três ou mais grupos.

Considere a linguagem L = { aⁿ bⁿ cⁿ | n ≥ 1 }, onde o número de a, b e c deve ser exatamente o mesmo.

Exemplos válidos incluem abc, aabbcc e aaabbbccc. Já palavras como aabbc, abbccc ou aaabbbcc não pertencem à linguagem.

Esse tipo de verificação exige um controle mais sofisticado, pois envolve várias dependências simultâneas.

Tipo 0 - Linguagens Recursivamente Enumeráveis

No topo da hierarquia estão as linguagens recursivamente enumeráveis, que representam o limite máximo do que pode ser computado. Elas permitem definir regras gerais sem restrições estruturais.

Usando todo o alfabeto { a, b, c, d, e }, podemos definir uma linguagem ainda mais complexa: L = { w ∈ { a, b, c, d, e }* | número de a = número de b = número de c = número de d = número de e }.

Exemplos válidos incluem abcde e aabbccddee. Já palavras como aabbccdde ou abcdd não satisfazem a condição.

Aqui estamos exigindo que cinco quantidades diferentes sejam iguais ao mesmo tempo, algo que só pode ser tratado por modelos com poder computacional máximo, como as Máquinas de Turing.
