Matriz de Adjacência

Neste artigo, exploraremos uma das formas mais comuns de representar grafos computacionalmente: a matriz de adjacência. Veremos como construí-la, como interpretá-la e quais são suas propriedades fundamentais, com um exemplo prático para consolidar o entendimento.

O que é uma Matriz de Adjacência?

Grafos podem ser representados de diversas formas dentro de um computador. Uma das mais utilizadas é a matriz de adjacência - uma estrutura matemática que permite visualizar, de forma compacta, quais vértices de um grafo estão conectados entre si.

Sua definição matemática é: Dado um grafo G, onde V(G) é o conjunto de vértices e E(G) é o conjunto de arestas, a matriz de adjacência é uma matriz n x n - sendo n o número de vértices do grafo. Cada posição da matriz, identificada por um par de vértices (u, v), armazena o número de arestas que conectam esses dois vértices - você entenderá melhor esse conceito com o exemplo, não se preocupe em entender agora.

Um detalhe importante: quando um vértice possui um loop - ou seja, uma aresta que parte e chega no mesmo vértice - esse loop é contado como duas arestas na posição correspondente da matriz, pois o vértice é terminal duas vezes.

Propriedades

A matriz de adjacência possui algumas propriedades importantes que facilitam sua interpretação:

  • Em grafos não-direcionados, a matriz é sempre simétrica - o valor da posição (u, v) é sempre igual ao valor da posição (v, u), pois se existe uma aresta de u para v, ela também vai de v para u.
  • O valor 0 em uma posição indica que não existe nenhuma aresta entre os dois vértices correspondentes.
  • O valor 1 indica a existência de uma única aresta entre os dois vértices.
  • Valores maiores que 1 indicam a existência de arestas paralelas - múltiplas arestas conectando os mesmos dois vértices - não há isso no exemplo.
  • O valor na diagonal principal da matriz representa loops - arestas que partem e chegam no mesmo vértice.

Resumo

  • Matriz de adjacência: matriz n x n que representa as conexões entre os vértices de um grafo.
  • Valor 0: indica ausência de aresta entre dois vértices.
  • Valor 1: indica a existência de uma aresta entre dois vértices.
  • Valor > 1: indica arestas paralelas entre dois vértices.
  • Loop: aresta que parte e chega no mesmo vértice - contado como 2 na diagonal principal.
  • Simetria: em grafos não-direcionados, a matriz de adjacência é sempre simétrica.
