Grafo Conectado

Neste artigo, exploraremos o conceito de grafo conectado - também chamado de grafo conexo. Veremos como identificar se um grafo é conectado ou desconectado, quais são os casos especiais e como esse conceito se relaciona com os tópicos anteriores.

O que é um Grafo Conectado?

Um grafo conectado é um grafo no qual sempre é possível encontrar um passeio entre qualquer par de vértices. Em outras palavras, nenhum vértice ou grupo de vértices fica isolado do restante do grafo - todos estão de alguma forma ligados entre si.

Formalmente, um grafo é conectado se, para qualquer divisão de seus vértices em dois grupos não-vazios X e Y, existe pelo menos uma aresta com um terminal em X e um terminal em Y. Se não existir tal aresta para alguma divisão possível, o grafo é chamado de desconectado.

Visualmente, identificar um grafo conectado é simples: basta verificar se o grafo está todo ligado em uma única peça. Um grafo desconectado possui partes separadas - chamadas de componentes - que não se comunicam entre si por nenhuma aresta.

Como Identificar um Grafo Desconectado?

Para provar que um grafo é desconectado basta encontrar qualquer par de vértices X e Y tal que não exista nenhum caminho que os conecte.

Casos Especiais

Grafo Trivial

O grafo trivial - aquele com um único vértice - é conectado por definição. Como não existem dois vértices distintos, não é possível encontrar um par de vértices que prove desconexão.

Grafos Vazios

Os grafos vazios - aqueles que não possuem arestas - com dois ou mais vértices são sempre desconectados. Como não possuem nenhuma aresta, qualquer pares de vértices não terá nenhuma aresta conectando os dois. A única exceção é o grafo trivial - o único grafo vazio que é conectado.

Grafo Completo

O grafo completo Kn é sempre conectado para qualquer n maior ou igual a 1. Como todo vértice é adjacente a todos os outros, qualquer par de vértices sempre terá arestas conectando os mesmos.

Resumo

  • Grafo conectado: grafo onde sempre existe um passeio entre qualquer par de vértices.
  • Grafo desconectado: grafo que possui componentes isoladas - grupos de vértices sem nenhuma aresta entre si.
  • Componente: parte isolada de um grafo desconectado.
  • O grafo trivial é conectado por definição.
  • Grafos vazios com 2 ou mais vértices são sempre desconectados.
  • O grafo completo Kn é sempre conectado.
