Grafo Regular e Cúbico

Neste artigo, exploraremos duas famílias especiais de grafos: o grafo regular - onde todos os vértices possuem o mesmo grau - e o grafo cúbico - um caso especial do grafo regular onde todos os vértices têm grau 3.

Grafo Regular

Um grafo regular é um grafo onde todos os vértices possuem exatamente o mesmo grau. Um grafo regular de grau k é chamado de k-regular.

Alguns exemplos de grafos regulares que já estudamos:

  • O grafo completo Kn é (n-1)-regular - cada vértice é adjacente a todos os outros n-1 vértices.
  • O grafo ciclo Cn é 2-regular - cada vértice possui exatamente 2 vizinhos.
  • O grafo vazio é 0-regular - todos os vértices têm grau 0.

Condição para Existência

Para gerar um grafo k-regular com n vértices, duas condições devem ser obedecidas:

  • n > k - o número de vértices deve ser maior que o grau.
  • n x k deve ser par - pois a soma dos graus de todos os vértices é sempre par (cada aresta contribui com 2 para a soma total dos graus).

Se qualquer uma dessas condições não for satisfeita, não é possível construir o grafo regular.

Grafo Cúbico

Um grafo cúbico é um caso especial de grafo regular onde todos os vértices têm grau 3 - ou seja, um grafo cúbico é um grafo 3-regular.

Dois exemplos clássicos de grafos cúbicos são o Grafo de Petersen e o Grafo do Cubo. O Grafo de Petersen é um dos grafos mais estudados na teoria dos grafos, sendo utilizado como contraexemplo em diversas conjecturas. Já o Grafo do Cubo representa as arestas e vértices de um cubo tridimensional - onde cada vértice do cubo é adjacente exatamente a outros 3 vértices.

Resumo

  • Grafo regular: grafo onde todos os vértices possuem o mesmo grau.
  • k-regular: grafo regular de grau k.
  • Para existir um grafo k-regular com n vértices: n > k e n x k deve ser par.
  • Grafo cúbico: grafo 3-regular - todos os vértices têm grau 3.
  • Exemplos clássicos de grafos cúbicos: Grafo de Petersen e Grafo do Cubo.
  • Grafo completo Kn é (n-1)-regular, grafo ciclo Cn é 2-regular e grafo vazio é 0-regular.
