Introdução a Bancos de Dados

O foco desta disciplina é apresentar os conceitos fundamentais de bancos de dados tradicionais, abordando organização, armazenamento, manipulação e gerenciamento de informações por meio de Sistemas Gerenciadores de Banco de Dados (SGBDs). Pois bem, comecemos do básico.

O que é um Banco de Dados?

Um Banco de Dados (BD) é uma coleção organizada de dados relacionados entre si, armazenados para um propósito específico. Os dados representam fatos conhecidos que possuem significado e podem ser utilizados para representar parte do mundo real.

Essa parte do mundo real representada pelo banco é chamada de mini-mundo ou universo de discurso. Um banco de dados não é apenas um conjunto aleatório de informações - ele é projetado, construído e populado para atender necessidades específicas de usuários ou aplicações.

Alguns exemplos de bancos de dados presentes no dia a dia:

  • Sistemas acadêmicos: controle de alunos, notas e disciplinas.
  • Sistemas bancários: transações, contas e clientes.
  • Redes sociais: perfis, publicações e conexões.
  • Lojas virtuais: produtos, pedidos e estoque.
  • Sistemas hospitalares: prontuários, consultas e medicamentos.

SGBD

O Sistema Gerenciador de Banco de Dados (SGBD) é o software responsável por criar, manipular, armazenar e controlar o acesso aos bancos de dados. Um sistema de banco de dados completo é formado pela combinação de três elementos: o SGBD, o Banco de Dados em si e as aplicações que utilizam os dados.

Principais funções do SGBD

O SGBD é responsável por uma ampla gama de funções que garantem o funcionamento correto e eficiente do sistema:

  • Definição da estrutura do banco.
  • Construção e armazenamento dos dados.
  • Manipulação e atualização das informações.
  • Compartilhamento de dados entre usuários.
  • Controle de acesso e segurança.
  • Backup e recuperação de falhas.
  • Processamento eficiente de consultas.

Natureza auto-descritiva

O SGBD mantém um catálogo contendo informações sobre a estrutura do banco, tipos de dados, restrições e organização das tabelas. Essas informações são chamadas de metadados - ou seja, dados sobre os próprios dados. Isso permite que o SGBD saiba como interpretar e manipular as informações armazenadas sem depender de cada aplicação individualmente.

Independência entre programas e dados

Uma das grandes vantagens do SGBD é permitir alterar a estrutura do banco sem a necessidade de modificar todas as aplicações que utilizam os dados. Isso reduz significativamente os custos de manutenção e facilita a evolução dos sistemas ao longo do tempo.

Abstração de dados

Os detalhes físicos de armazenamento são ocultados dos usuários e desenvolvedores. Dessa forma, quem trabalha com o banco pode focar na modelagem e organização lógica das informações, sem precisar se preocupar com como os dados são fisicamente guardados no disco.

Múltiplas visões dos dados

Diferentes usuários podem visualizar apenas os dados relevantes para suas funções. Em um sistema universitário, por exemplo, alunos visualizam suas notas, professores visualizam suas turmas e administradores têm acesso a relatórios gerais. Cada um enxerga uma visão diferente do mesmo banco de dados.

Controle de concorrência

O SGBD permite que vários usuários acessem o banco simultaneamente sem comprometer a integridade das informações. Esse controle é essencial em sistemas que exigem alta disponibilidade, como sistemas bancários, lojas virtuais e aplicações corporativas.

Transações

Uma transação representa um conjunto de operações executadas como uma única unidade lógica - ou todas acontecem com sucesso, ou nenhuma é aplicada. Exemplos comuns incluem transferências bancárias, compras online e matrículas acadêmicas. O SGBD garante que essas operações sejam executadas corretamente, mesmo em situações de falha.

Outros benefícios dos SGBDs

  • Redução de redundância de dados.
  • Controle de acesso não autorizado.
  • Maior integridade dos dados.
  • Processamento eficiente de consultas com uso de índices.
  • Serviços de backup e recuperação.

Aplicações de Bancos de Dados

Bancos de dados estão presentes em praticamente todas as áreas da computação e do cotidiano. Suas aplicações vão desde sistemas tradicionais até soluções modernas de grande escala.

Aplicações tradicionais

  • Dados numéricos e textuais em sistemas empresariais.
  • Controle acadêmico - alunos, notas e disciplinas.
  • Sistemas de gestão financeira e contábil.

Aplicações modernas

  • Armazenamento de multimídia - imagens, vídeos e áudios.
  • Dados geográficos e sistemas de navegação.
  • Bioinformática e análise de genoma.
  • Data Warehouses para análise de grandes volumes de dados.
  • Sistemas móveis e em tempo real.
  • Redes sociais e motores de busca.

Conceitos Importantes

Antes de avançarmos, é importante familiarizar-se com alguns conceitos fundamentais que aparecem em todo o estudo de bancos de dados.

Entidades

Entidades representam objetos do mundo real que serão armazenados no banco de dados. Em um sistema universitário, por exemplo, as entidades seriam Aluno, Professor, Disciplina e Departamento.

Relacionamentos

Relacionamentos representam associações entre entidades. No mesmo sistema universitário: um Aluno cursa uma Disciplina, um Professor ministra uma Turma e uma Disciplina pertence a um Departamento.

Usuários de Banco de Dados

Em um sistema de banco de dados, diferentes perfis de usuários interagem com o sistema de formas distintas:

  • Usuários finais - utilizam as aplicações para consultar e inserir dados.
  • Desenvolvedores - constroem as aplicações que acessam o banco.
  • Administradores de Banco de Dados (DBAs) - gerenciam, monitoram e otimizam o banco.
  • Projetistas do SGBD - desenvolvem o próprio software gerenciador.

Resumo

  • Banco de Dados: coleção organizada de dados relacionados, projetada para um propósito específico.
  • Mini-mundo: parte do mundo real representada pelo banco.
  • SGBD: software responsável por criar, manipular e controlar o acesso ao banco.
  • Metadados: dados sobre a estrutura do próprio banco, mantidos no catálogo do SGBD.
  • Transação: conjunto de operações executadas como uma única unidade lógica.
  • Entidade: objeto do mundo real armazenado no banco.
  • Relacionamento: associação entre entidades.
